# रील J1 (v2) — `public static void main(String[] args)`: रटो मत, बोर्ड पर बनाओ

**सीरीज़:** कोड की एक लाइन · **स्टाइल:** प्रोफ़ेसर बोर्ड (`ai-channel/STYLE-code-reels.md`) · **लंबाई:** करीब 85–90 सेकंड · **फ़ॉर्मेट:** 9:16 · **एआई क्लिप:** 0
**आइडिया:** लाइन के 5 शब्द एक-एक करके रटवाने की जगह, **जेवीएम की 5 ज़रूरतों** से लाइन को बोर्ड पर **खुद बनाते** हैं: नाम → वापसी → बिना ऑब्जेक्ट → इजाज़त → इनपुट। आख़िर में ट्विस्ट: जो दूसरे कदम पर लिखा था (`void main()`), Java 25 में वही छोटा रूप चल जाता है।

## 🎙️ वॉइसओवर (सिर्फ़ पढ़ने के लिए)

> रिकॉर्डिंग: एक फ़ाइल `J1.wav`। टोन: क्लास में समझाते हुए प्रोफ़ेसर, जल्दबाज़ी नहीं। **मोटे अक्षर** = ज़ोर। `...` = छोटा ठहराव। `(रुको)` = 1–2 सेकंड चुप, ताकि देखने वाला सोचे।

जब तुम जावा प्रोग्राम रन करते हो... तो जावा को कैसे पता चलता है कि **शुरू कहाँ से** करना है? जवाब है — ये एक लाइन। पर आज इसे रटेंगे नहीं। **बोर्ड पर खुद बनाएँगे।**

सोचो — जेवीएम, यानी जावा वर्चुअल मशीन, एक मेहमान है, जो तुम्हारे प्रोग्राम की बिल्डिंग में पहली बार आ रहा है। उसे बस एक **दरवाज़ा** चाहिए। चलो, उसकी ज़रूरतें एक-एक करके पूरी करते हैं।

**पहली ज़रूरत —** दरवाज़े का नाम पहले से तय हो। तो जावा ने नियम बना दिया — नाम होगा **"मेन"**। जेवीएम ठीक इसी नाम को ढूंढती है।

**दूसरी —** क्या जेवीएम को बदले में कुछ चाहिए? (रुको) नहीं। उसे बस प्रोग्राम चलाना है। इसलिए रिटर्न टाइप — **"वॉइड"**, यानी कुछ भी वापस नहीं।

**तीसरी ज़रूरत सबसे मज़ेदार है।** जावा में किसी मेथड को बुलाने के लिए आम तौर पर पहले ऑब्जेक्ट बनाना पड़ता है। पर रुको... प्रोग्राम अभी शुरू ही नहीं हुआ — तो ऑब्जेक्ट **बनाएगा कौन?** (रुको) कोई नहीं! इसलिए **"स्टैटिक"** — यानी बिना ऑब्जेक्ट बनाए, सीधे क्लास के नाम से बुलाओ।

**चौथी —** जेवीएम तुम्हारी क्लास के **बाहर** खड़ी है। बाहर वाले को अंदर आने की इजाज़त चाहिए। इसलिए **"पब्लिक"** — यानी सबके लिए खुला।

**और आख़िरी सवाल —** अगर रन करते वक्त बाहर से कुछ भेजना हो, तो? उसके लिए **"स्ट्रिंग ऐरे आर्ग्स"** — यानी टेक्स्ट की एक लिस्ट। जैसे — जावा मेन हेलो दस। तो आर्ग्स ज़ीरो में आएगा "हेलो", और आर्ग्स वन में "दस"। और ध्यान दो — ये दस भी **टेक्स्ट** है, नंबर नहीं।

तो देखा? ये लाइन रटने की चीज़ नहीं है। ये जेवीएम की **पाँच ज़रूरतों का जवाब** है — नाम, वापसी, बिना ऑब्जेक्ट, इजाज़त, और इनपुट।

और अब सबसे इंटरेस्टिंग बात — याद है, बोर्ड पर दूसरे कदम पर हमने क्या लिखा था? **"वॉइड मेन"**। **जावा 25 से** नए प्रोग्राम में ठीक यही छोटा रूप भी चल जाता है! पर कॉलेज, इंटरव्यू और पुराने प्रोजेक्ट्स में ज़्यादातर पूरी लाइन ही दिखती है।

एक इंटरव्यू सवाल — अगर मेन को **प्राइवेट** कर दें, तो? (रुको) प्रोग्राम कंपाइल तो हो जाएगा... पर **शुरू नहीं होगा।** क्यों? जवाब कमेंट में लिखो।

रटो मत, समझो। सेव कर लो — एग्ज़ाम से पहले काम आएगी।

## बोर्ड + स्क्रीन (एडिट के लिए)

> **स्टाइल: प्रोफ़ेसर बोर्ड।** गहरा स्लेट बैकग्राउंड (#14181D) और उस पर बहुत हल्की ग्राफ़-पेपर ग्रिड। कोड बीच में JetBrains Mono में। प्रोफ़ेसर के निशान (तीर, घेरे, अंडरलाइन, टिक) **हाथ से खींचे चॉक जैसे** पीले/नारंगी स्ट्रोक में। हिंदी नोट्स हाथ की लिखावट वाले फ़ॉन्ट (Kalam) में। एक छोटा "लेज़र-पॉइंटर" बिंदु उस चीज़ पर जाता है जिसकी बात हो रही है।
> **बाईं तरफ़** "जेवीएम की ज़रूरतें" वाली लिस्ट हर कदम के साथ बढ़ती जाती है (1 → 5)।

**⏱ 0–8 सेकंड · हुक**
🎙️ जब तुम जावा प्रोग्राम रन करते हो... बोर्ड पर खुद बनाएँगे।
🎬 बोर्ड पर पूरी लाइन `public static void main(String[] args)` धुंधली दिखती है → उस पर चॉक से बड़ा "?" और लिखावट में "शुरू कहाँ से?" → फिर लाइन मिट जाती है (डस्टर स्वाइप) और बोर्ड खाली। कोने में लिखावट: "रटो मत → बनाओ"।

**⏱ 8–16 सेकंड · सेटअप**
🎙️ सोचो — जेवीएम... एक-एक करके पूरी करते हैं।
🎬 सिंपल लाइन-ड्रॉइंग: एक बिल्डिंग = `class Main` (डिब्बा), उसके बाहर छोटा किरदार जिस पर बैज "JVM"। बिल्डिंग पर दरवाज़े की आउटलाइन बनती है। बाईं तरफ़ खाली लिस्ट का शीर्षक: "जेवीएम की ज़रूरतें"।

**⏱ 16–23 सेकंड · कदम 1: नाम → `main`**
🎙️ पहली ज़रूरत — दरवाज़े का नाम पहले से तय हो... जेवीएम ठीक इसी नाम को ढूंढती है।
🎬 दरवाज़े पर `main()` टाइप होता है। लिस्ट: "1. तय नाम ✓"। पॉइंटर `main` पर।

**⏱ 23–30 सेकंड · कदम 2: वापसी → `void`**
🎙️ दूसरी — क्या जेवीएम को बदले में कुछ चाहिए? ... कुछ भी वापस नहीं।
🎬 (रुको वाले पल पर बोर्ड पर "?" टिमटिमाता है)। फिर `main()` के बाएँ `void ` खिसककर आता है → `void main()`। मेथड से वापस JVM की तरफ़ जाता तीर, उस पर "∅ कुछ नहीं"। लिस्ट: "2. कुछ वापस नहीं ✓"। **(इस फ़्रेम को याद रखना — ट्विस्ट में वापस आएगा।)**

**⏱ 30–42 सेकंड · कदम 3: बिना ऑब्जेक्ट → `static`**
🎙️ तीसरी ज़रूरत सबसे मज़ेदार है... सीधे क्लास के नाम से बुलाओ।
🎬 बोर्ड के कोने में छोटा उदाहरण: `obj = new Main();` → `obj.main();`। फिर "प्रोग्राम अभी शुरू नहीं हुआ" पर `new Main()` पर लाल चॉक से क्रॉस, लिखावट "ऑब्जेक्ट कौन बनाएगा? 🤷"। फिर `static ` खिसककर आता है → `static void main()`। तीर: `Main.main()` "क्लास के नाम से सीधा"। लिस्ट: "3. बिना ऑब्जेक्ट ✓"।

**⏱ 42–49 सेकंड · कदम 4: इजाज़त → `public`**
🎙️ चौथी — जेवीएम तुम्हारी क्लास के बाहर खड़ी है... सबके लिए खुला।
🎬 JVM किरदार बिल्डिंग के बाहर, दरवाज़े पर ताला 🔒 → `public ` खिसककर आता है → ताला खुलता है, JVM अंदर। लाइन: `public static void main()`। लिस्ट: "4. बाहर से इजाज़त ✓"।

**⏱ 49–63 सेकंड · कदम 5: इनपुट → `String[] args`**
🎙️ और आख़िरी सवाल... ये दस भी टेक्स्ट है, नंबर नहीं।
🎬 कोष्ठक के अंदर `String[] args` टाइप होता है → **पूरी लाइन बन गई।** बोर्ड पर चॉक से तीन डिब्बों वाली लिस्ट बनती है (array)। फिर नीचे टर्मिनल कार्ड:
```
$ java Main Hello 10
```
डिब्बों में भरता है: `args[0] → "Hello"`, `args[1] → "10"`। "10" पर नारंगी घेरा + लिखावट "ये भी text है! नंबर चाहिए → `Integer.parseInt()`"। लिस्ट: "5. बाहर से इनपुट ✓"।

**⏱ 63–70 सेकंड · सार**
🎙️ तो देखा? ये लाइन रटने की चीज़ नहीं है... और इनपुट।
🎬 पूरी लाइन के हर शब्द के नीचे उसकी ज़रूरत का छोटा लेबल (लिखावट): `public`→इजाज़त, `static`→बिना ऑब्जेक्ट, `void`→वापसी नहीं, `main`→नाम, `String[] args`→इनपुट। बाईं लिस्ट के पाँचों टिक एक साथ चमकते हैं।

**⏱ 70–79 सेकंड · ट्विस्ट: Java 25**
🎙️ और अब सबसे इंटरेस्टिंग बात... ज़्यादातर पूरी लाइन ही दिखती है।
🎬 "रीवाइंड" इफ़ेक्ट → कदम 2 वाला फ़्रेम `void main()` वापस आता है, उस पर पीले चॉक का घेरा + टैग "**Java 25+**"। साथ में चलने वाला छोटा कोड:
```java
void main() {
    IO.println("Hello");
}
```
नीचे लिखावट: "कॉलेज / इंटरव्यू → पूरी लाइन"।

**⏱ 79–86 सेकंड · इंटरव्यू सवाल**
🎙️ एक इंटरव्यू सवाल... जवाब कमेंट में लिखो।
🎬 कार्ड: "❓ इंटरव्यू: `private static void main(...)`?" → (रुको) पर 3-2-1 टाइमर का छोटा घेरा → जवाब: "कंपाइल ✓ · रन ✗ (JVM को एंट्री नहीं मिलेगी)" → "क्यों? 👇 कमेंट"।

**⏱ 86–90 सेकंड · सीटीए**
🎙️ रटो मत, समझो। सेव कर लो — एग्ज़ाम से पहले काम आएगी।
🎬 पूरी लाइन + लिखावट "रटो मत, समझो"। "सेव 🔖" टिक होता है। आख़िरी कार्ड: "फ़ॉलो · कोड की एक लाइन" + हैंडल।

## पिछले वर्ज़न से क्या बेहतर हुआ
- **क्रम बदला:** बाएँ से दाएँ शब्द समझाने की जगह लाइन **ज़रूरत के हिसाब से बनती** है (main → void → static → public → args)। हर शब्द का "क्यों" पहले आता है, शब्द बाद में। यही प्रोफ़ेसर वाला तरीका है।
- **सोचने के पल:** 3 जगह "(रुको)", ताकि देखने वाला खुद जवाब सोचे। इससे रील पूरी देखी जाती है।
- **ट्विस्ट कहानी से जुड़ा:** Java 25 वाली बात अब अलग से नहीं आती, दूसरे कदम (`void main()`) का पे-ऑफ़ बनती है।
- **इंटरव्यू सवाल:** `private` वाला सवाल हर Java वर्ज़न में सही है, और कमेंट्स लाता है।
- **रेफ़रेंस रील से अलग लुक:** काले बैकग्राउंड और टेक्स्ट की जगह प्रोफ़ेसर-बोर्ड, चॉक वाले निशान, बिल्डिंग-दरवाज़ा वाली मिसाल, और बढ़ती चेकलिस्ट।

## सोर्स
- JEP 512: Compact Source Files and Instance Main Methods, JDK 25 में final (`main` के लिए `public`/`static`/`String[] args` ज़रूरी नहीं; `void main()` चलता है): [openjdk.org/jeps/512](https://openjdk.org/jeps/512) · [InfoQ, May 2025](https://www.infoq.com/news/2025/05/jdk25-instance-main-methods)
- Launcher पहले `main(String[])` ढूंढता है, फिर `main()`: [OpenJDK compiler-dev, JDK-8357016](https://mail.openjdk.org/pipermail/compiler-dev/2025-May/030458.html)
- **टेस्ट हो चुका (15 Oct 2026, OpenJDK 21.0.12 + 25.0.4):** (1) `java Main Hello 10` → `argument: Hello` / `argument: 10` ✓ (2) `private static void main` → कंपाइल ✓, रन पर "Main method not found" — Java 21 और 25 दोनों में ✓ (3) Java 25 पर `void main() { IO.println("Hello"); }` → `Hello` ✓ (compact फ़ाइल और class वाली, दोनों)
