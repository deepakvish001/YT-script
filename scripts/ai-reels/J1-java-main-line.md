# रील J1 (v3) — `public static void main(String[] args)`: आज तुम JVM हो

**सीरीज़:** कोड की एक लाइन · **स्टाइल:** प्रोफ़ेसर बोर्ड (`ai-channel/STYLE-code-reels.md`) · **लंबाई:** करीब 95–100 सेकंड · **फ़ॉर्मेट:** 9:16 · **एआई क्लिप:** 0
**आइडिया:** प्रोफ़ेसर वाला गेम — "मान लो तुम JVM हो"। JVM के **5 सवाल** पूछो, और हर सवाल का जवाब एक शब्द बनकर बोर्ड पर लाइन में जुड़ता जाए: `main` → `void` → `static` → `public` → `String[] args`। बीच में `"10" + 5 = 105` वाला चौंकाने वाला टेस्ट, आख़िर में Java 25 का ट्विस्ट और इंटरव्यू सवाल।
**भाषा:** बोलचाल की हिंदी देवनागरी में; कोड और टेक शब्द (JVM, method, object, public…) अंग्रेज़ी में ही, जैसे तुम्हारी अपनी स्क्रिप्ट में।

## 🎙️ वॉइसओवर (सिर्फ़ पढ़ने के लिए)

> रिकॉर्डिंग: एक फ़ाइल `J1.wav`। टोन: क्लास में बोर्ड के सामने खड़ा प्रोफ़ेसर — आराम से, मुस्कुराते हुए, जल्दबाज़ी नहीं। **मोटे अक्षर** = ज़ोर। `...` = छोटा ठहराव। `(रुको)` = 1–2 सेकंड चुप। हर नया पैराग्राफ़ = नई साँस।
> पढ़ने का तरीका: `args[0]` = "args ज़ीरो", `args[1]` = "args वन", `String[] args` = "String array args"।

**1. हुक**
ये line तुमने सौ बार लिखी होगी।
पर अगर interview में कोई पूछे — इसमें **static क्यों है?** ... तो? (रुको)
आज इसे रटेंगे नहीं। आज इसे **ज़ीरो से बनाएँगे।**

**2. गेम**
एक छोटा सा game खेलते हैं। मान लो — **तुम JVM हो।** यानी Java Virtual Machine, जो हर Java program को चलाती है।
तुम्हारे सामने एक class है, अंदर ढेर सारे methods। और तुम्हारा काम सिर्फ़ एक — program **start** करना।
तो JVM बनकर सोचो... तुम्हारा **पहला सवाल** क्या होगा?

**3. सवाल 1 → `main`**
"शुरू **कहाँ से** करूँ?" इतने methods में से पहला कौन सा?
इसलिए Java ने एक नाम fix कर दिया — **main**। JVM सिर्फ़ इसी नाम को ढूंढती है।
नाम बदला... तो program start ही नहीं होगा।

**4. सवाल 2 → `void`**
दूसरा सवाल — "काम ख़त्म होने पर, क्या मुझे **कुछ वापस** चाहिए?" (रुको)
नहीं। JVM को बस program चलाना है। इसलिए **void** — यानी कुछ भी return नहीं।
बोर्ड का ये हिस्सा याद रखना... **आख़िर में ये वापस आएगा।**

**5. सवाल 3 → `static`**
अब तीसरा सवाल — **ध्यान से सुनो**, शुरू वाला interview सवाल यही है।
Java में normally method call करने के लिए पहले **object** बनाना पड़ता है।
पर program अभी शुरू ही नहीं हुआ — कोई object है ही नहीं। और बनाए भी, तो किस constructor से? कौन सी values डालकर?
JVM ये अंदाज़ा नहीं लगाना चाहती। (रुको)
इसलिए ये झंझट ही हटा दिया — **static**। यानी **बिना object बनाए**, सीधे class के नाम से call।

**6. सवाल 4 → `public`**
चौथा सवाल — "मैं तो class के **बाहर** खड़ी हूँ, अंदर कैसे आऊँ?"
बाहर वाले के लिए दरवाज़ा खुला होना चाहिए। इसलिए **public** — यानी सबके लिए open।

**7. सवाल 5 → `String[] args`**
और आख़िरी सवाल — "user ने program चलाते वक़्त **कुछ भेजा**, तो उसे रखूँ कहाँ?"
उसके लिए **String[] args** — यानी text की एक list।
Terminal में लिखो — java Main Hello 10। तो args[0] में आएगा **Hello**, और args[1] में **10**।

**8. टेस्ट: 10 + 5**
अब एक मज़ेदार test। args[1] में 5 जोड़ो। जवाब 15? (रुको)
नहीं... **105!**
क्योंकि ये 10 number नहीं, **text** है। text में 5 जोड़ा, तो वो बस साथ में **चिपक** गया।
Number चाहिए, तो पहले **Integer.parseInt** — तब मिलेगा 15।

**9. सार**
अब पूरी line फिर से पढ़ो —
public — अंदर आने दो। static — बिना object के। void — कुछ वापस नहीं। main — यहीं से शुरू। और String[] args — बाहर से input।
ये रटने वाला rule नहीं है। ये JVM के **पाँच सवालों के पाँच जवाब** हैं।

**10. ट्विस्ट**
और अब सबसे interesting बात — याद है, दूसरे सवाल पर बोर्ड पर क्या लिखा था? **void main()**।
**Java 25 से** नए program में यही छोटा रूप भी चल जाता है!
पर college, interview और पुराने projects में पूरी line ही मिलेगी। इसलिए समझना **दोनों** है।

**11. इंटरव्यू सवाल**
अब तुम्हारी बारी — main को **private** कर दें, तो? (रुको)
Compile हो जाएगा... पर program **start नहीं होगा।**
क्यों? Hint — चौथे सवाल में छुपा है। जवाब **comment** में लिखो।

**12. सीटीए**
रटो मत, **समझो।**
Save कर लो — और उस दोस्त को भेजो जो ये line आज तक रटता आया है।

## v2 से क्या बदला
- **भाषा तुम्हारी अपनी स्क्रिप्ट जैसी:** हिंदी देवनागरी में, पर JVM, method, object, public जैसे शब्द अंग्रेज़ी में। "जेवीएम", "स्टैटिक" जैसा अटपटा लिप्यंतरण हटाया।
- **मेहमान-बिल्डिंग वाली मिसाल हटाई:** अब सीधा गेम — **"मान लो तुम JVM हो"**। देखने वाला खुद JVM बनकर हर सवाल सोचता है।
- **हुक में खुला सवाल:** "static क्यों है?" — इसका जवाब तीसरे सवाल पर मिलता है, इसलिए बीच में छोड़ना मुश्किल।
- **`static` की वजह ज़्यादा सही:** "object है ही नहीं, और बनाए भी तो किस constructor से?"
- **नया "आहा" पल:** `"10" + 5 = 105`। ये टेस्ट करके दिखाता है कि args text है।
- **इंटरव्यू सवाल का hint** चौथे सवाल से जुड़ा, ताकि कमेंट में सही जवाब आएँ।

## ध्यान रखो
- "Java 25 में पुरानी लाइन बंद हो गई" **मत** बोलो। पूरी लाइन आज भी पूरी तरह चलती है।
- `static` / `public` वाली बातें **क्लासिक Java** का नियम हैं। Java 25 में बिना `static` वाला `main` भी चल जाता है (टेस्ट किया)। इसलिए ट्विस्ट वाला हिस्सा ज़रूर रखो।
- `private` वाला जवाब: "compile हो जाएगा, पर run नहीं होगा"। "compile error" मत बोलो।
- स्क्रीन का हर कोड असली और चलने वाला हो। `IO.println` Java 25 का है; पुराने वर्ज़न में `System.out.println`।
- Oracle/Java लोगो या "Duke" कैरेक्टर नहीं।

## सोर्स
- JEP 512: Compact Source Files and Instance Main Methods, JDK 25 में final (`main` के लिए `public`/`static`/`String[] args` ज़रूरी नहीं; `void main()` चलता है): [openjdk.org/jeps/512](https://openjdk.org/jeps/512) · [InfoQ, May 2025](https://www.infoq.com/news/2025/05/jdk25-instance-main-methods)
- Launcher पहले `main(String[])` ढूंढता है, फिर `main()`: [OpenJDK compiler-dev, JDK-8357016](https://mail.openjdk.org/pipermail/compiler-dev/2025-May/030458.html)
- **टेस्ट हो चुका (15 Oct 2026, OpenJDK 21.0.12 + 25.0.4):**
  1. `java Main Hello 10` → `args[0]` = `Hello`, `args[1]` = `10` ✓
  2. `args[1] + 5` → `105`, और `Integer.parseInt(args[1]) + 5` → `15` ✓ (21 और 25)
  3. `main` का नाम `start` किया → कंपाइल ✓, रन पर "Main method not found" ✓ (21 और 25)
  4. `private static void main` → कंपाइल ✓, रन पर "Main method not found" ✓ (21 और 25)
  5. `static` हटाया → Java 21: "Main method is not static" ✗ · Java 25: चल गया ✓
  6. Java 25 पर `void main() { IO.println("Hello"); }` → `Hello` ✓
