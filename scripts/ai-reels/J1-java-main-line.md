# रील J1 — `public static void main(String[] args)` का हर शब्द

**सीरीज़:** कोड की एक लाइन (नई) · **लंबाई:** करीब 60–65 सेकंड · **फ़ॉर्मेट:** 9:16 · **एआई क्लिप:** 0
**एक सीख:** इस लाइन का हर शब्द क्यों है — और Java 25 में क्या बदला।

## 🎙️ वॉइसओवर (सिर्फ़ पढ़ने के लिए)

> रिकॉर्डिंग: एक ही फ़ाइल `J1.wav`। शुरू और अंत में 2 सेकंड चुप। **मोटे अक्षर** = ज़ोर। `...` = छोटा ठहराव।

दोस्तो, जावा सीखने वाले हर इंसान ने ये लाइन लिखी है... पर क्या तुम्हें इसके **हर एक शब्द** का मतलब पता है? चलो, एक-एक शब्द तोड़कर समझते हैं।

**पहला — पब्लिक।** यानी सबके लिए खुला। प्रोग्राम चलाते ही जेवीएम, यानी जावा वर्चुअल मशीन, तुम्हारी क्लास के बाहर से इस मेथड को बुलाती है। दरवाज़ा बंद हुआ, तो वो अंदर आ ही नहीं पाएगी। इसीलिए क्लासिक जावा में मेन हमेशा पब्लिक लिखी जाती है।

**दूसरा — स्टैटिक।** यानी ऑब्जेक्ट बनाए बिना बुलाई जा सके। प्रोग्राम शुरू होते वक्त तुम्हारी क्लास का कोई ऑब्जेक्ट होता ही नहीं — तो जेवीएम सीधे क्लास के नाम से मेन को बुला लेती है।

**तीसरा — वॉइड।** यानी ये मेथड कुछ भी वापस नहीं लौटाती। जेवीएम को कोई वैल्यू नहीं चाहिए — बस प्रोग्राम चल जाए।

**चौथा — मेन।** ये सिर्फ़ एक नाम है... पर जावा का फ़िक्स एंट्री गेट। जेवीएम ठीक इसी नाम को ढूंढती है। नाम बदला — तो एरर: मेन मेथड मिली ही नहीं।

**और आख़िरी — स्ट्रिंग ऐरे आर्ग्स।** स्ट्रिंग ऐरे यानी टेक्स्ट की एक लिस्ट, और आर्ग्स यानी आर्ग्युमेंट्स — वो वैल्यूज़ जो तुम प्रोग्राम चलाते वक्त बाहर से भेजते हो। जैसे — जावा मेन हेलो दस। तो आर्ग्स ज़ीरो में आएगा "हेलो", और आर्ग्स वन में "दस"। और ध्यान दो — ये दस भी **टेक्स्ट** बनकर आता है, नंबर नहीं।

तो पूरी लाइन का मतलब — ये जावा प्रोग्राम का **एंट्री गेट** है, जहाँ से सब शुरू होता है।

और अब सबसे इंटरेस्टिंग बात — **जावा 25 से** नए प्रोग्राम में सिर्फ़ "वॉइड मेन" भी चल जाता है! पर कॉलेज, इंटरव्यू और पुराने प्रोजेक्ट्स में ज़्यादातर यही पूरी लाइन दिखती है — इसलिए इसे समझना ज़रूरी है।

कॉन्सेप्ट क्लियर हुआ हो, तो फ़ॉलो कर लो — और कमेंट में बताओ, अगली रील कोड की किस लाइन पर बनाऊँ?

## स्क्रिप्ट + स्क्रीन (एडिट के लिए) — स्टाइल: `ai-channel/STYLE-code-reels.md`

> पूरी रील काले बैकग्राउंड पर। ऊपर हमेशा कोड लाइन `public static void main(String[] args)` (सफ़ेद, बोल्ड)। जिस शब्द की बात हो, वो लाइन में **सुनहरा + अंडरलाइन**। बीच में वही शब्द बड़ा सुनहरा → पतला सफ़ेद तीर नीचे बनता है → छोटी व्याख्या (सफ़ेद, ज़रूरी शब्द नारंगी)।

**⏱ 0–5 सेकंड · हुक**
🎙️ दोस्तो, जावा सीखने वाले हर इंसान ने ये लाइन लिखी है... पर क्या तुम्हें इसके हर एक शब्द का मतलब पता है? चलो, एक-एक शब्द तोड़कर समझते हैं।
🎬 बीच में कोड लाइन टाइप होती है (कर्सर के साथ), फिर ऊपर खिसककर अपनी जगह पर रुकती है।

**⏱ 5–15 सेकंड · public**
🎙️ पहला — पब्लिक। यानी सबके लिए खुला... इसीलिए क्लासिक जावा में मेन हमेशा पब्लिक लिखी जाती है।
🎬 लाइन में `public` सुनहरा+अंडरलाइन। बीच: **public** → तीर → "**JVM** इसे क्लास के *बाहर से* बुला सके"

**⏱ 15–24 सेकंड · static**
🎙️ दूसरा — स्टैटिक... जेवीएम सीधे क्लास के नाम से मेन को बुला लेती है।
🎬 `static` हाइलाइट। बीच: **static** → तीर → "बिना **object** बनाए, क्लास के नाम से सीधा call"

**⏱ 24–30 सेकंड · void**
🎙️ तीसरा — वॉइड... बस प्रोग्राम चल जाए।
🎬 `void` हाइलाइट। बीच: **void** → तीर → "**JVM** को कुछ भी **return** नहीं करता"

**⏱ 30–38 सेकंड · main**
🎙️ चौथा — मेन... नाम बदला — तो एरर: मेन मेथड मिली ही नहीं।
🎬 `main` हाइलाइट। बीच: **main** → तीर → "वो **नाम** जिसे **JVM** ढूंढती है"। फिर `main` पल भर को `start` बनता है → नीचे लाल लाइन "Error: main method नहीं मिली" → वापस `main`।

**⏱ 38–53 सेकंड · String[] args**
🎙️ और आख़िरी — स्ट्रिंग ऐरे आर्ग्स... ये दस भी टेक्स्ट बनकर आता है, नंबर नहीं।
🎬 `(String[] args)` हाइलाइट। बीच: **(String[] args)** → तीर → "बाहर से आई **text** values की लिस्ट"। फिर VS Code जैसा डार्क एडिटर स्लाइड होता है:
```java
public class Main {
    public static void main(String[] args) {
        for (int i = 0; i < args.length; i++) {
            System.out.println("argument: " + args[i]);
        }
    }
}
```
नीचे तीर → टर्मिनल: `java Main Hello 10` → `argument: Hello` / `argument: 10`। "10" के पास छोटा नारंगी टैग: "ये भी text है"।

**⏱ 53–57 सेकंड · सार**
🎙️ तो पूरी लाइन का मतलब — ये जावा प्रोग्राम का एंट्री गेट है...
🎬 हाइलाइट हटती है, पूरी लाइन बीच में → तीर → सुनहरा "**Entry Point**" + छोटा "यहीं से प्रोग्राम शुरू"।

**⏱ 57–65 सेकंड · ट्विस्ट + सीटीए**
🎙️ और अब सबसे इंटरेस्टिंग बात — जावा 25 से... कमेंट में बताओ, अगली रील कोड की किस लाइन पर बनाऊँ?
🎬 पुरानी लाइन ऊपर छोटी होती है; नीचे नया कोड टाइप होता है: `void main() { IO.println("Hello"); }` + सुनहरा टैग "**Java 25+**"। फिर छोटा टेक्स्ट "कॉलेज / इंटरव्यू → पूरी लाइन"। आख़िर में सुनहरा "**FOLLOW FOR MORE**" + इंस्टाग्राम आइकन + हैंडल।

## तुम्हारी स्क्रिप्ट से क्या बदला (और क्यों)
1. **"इस लाइन के बिना प्रोग्राम शुरू ही नहीं होता"** → अब पूरी तरह सच नहीं। Java 25 (सितंबर 2025) से `void main()` भी चलता है (JEP 512)। इसलिए हुक बदला और आख़िर में ये बात ट्विस्ट बनाकर डाली।
2. **"main हमेशा public होती है"** → "क्लासिक जावा में"। Java 25 में `public` ज़रूरी नहीं रहा।
3. **"string का मतलब string का array"** → गलत था। `String` अकेले एक टेक्स्ट है, `String[]` यानी टेक्स्ट की लिस्ट (array)।
4. **उदाहरण अधूरा था** ("output public static void main आएगा" जैसा)। अब साफ़: `java Main Hello 10` → `args[0]="Hello"`, `args[1]="10"`। साथ में ये सीख कि नंबर भी टेक्स्ट बनकर आते हैं।
5. **"JVM बाहर से आती है"** → "JVM तुम्हारी क्लास के बाहर से मेथड को बुलाती है" (ज़्यादा साफ़)।
6. "नाम बदला तो एरर" वाली लाइन में एरर का हूबहू मैसेज नहीं बोला, क्योंकि Java के अलग-अलग वर्ज़न में मैसेज अलग है।
