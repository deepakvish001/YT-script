# P10 · Clone वही, ग्राहक नया
**Series:** प्लेसमेंट का सच · **लंबाई:** करीब 73 सेकंड · **Keyword:** PIVOT · **एक सीख:** Clone का code मत फेंको, बस उसे एक असली इंसान की असली problem पर लगा दो, deploy करो और एक सच्चा number लिखो।

## 🎙️ वॉइसओवर
तुमने तीन हफ्ते लगाकर Netflix clone बनाया, और recruiter उसे बिना रुके scroll कर गया, क्योंकि वो ऐसे कई clones देख चुका था। Netflix को भी नहीं पता होगा कि GitHub पर उसके इतने भाई बहन घूम रहे हैं। तुम्हें अपना clone खास IKEA effect की वजह से लगता है, यानी खुद मेहनत से बनाई चीज़ हमें ज़्यादा कीमती लगती है। लेकिन recruiter पर von Restorff effect चलता है, यानी एक जैसी चीज़ों की भीड़ में जो अलग दिखे, वही याद रहता है। तो code मत फेंको, बस मोहल्ला test लगाओ, यानी क्या मोहल्ले या college का कोई असली इंसान इसे कल से use कर सकता है? जैसे e-commerce clone को गली की kirana दुकान का order और stock app बना दो, जहाँ uncle को पता चले कि कौनसा सामान खत्म होने वाला है। या Netflix clone को college lectures की library बना दो, जहाँ हर student का progress save हो और exam से पहले बाकी lectures दिख जाएँ। फिर deploy करो, असली लोगों से use करवाओ, और एक सच्चा number लिखो, जैसे हफ्ते के orders। अब interview में तुम्हारे पास features की list नहीं, असली कहानी होगी। Comment में PIVOT लिखो, मैं तुम्हें clone upgrade sheet DM कर दूँगा, और follow कर लो।

## 🎬 स्क्रीन + मीम
- **Hook:** stick figure recruiter laptop पर scroll कर रहा है, screen पर एक के नीचे एक cards: "Netflix Clone", "Netflix Clone", "Netflix Clone 2.0", "NetflixClone-final-final"; तुम्हारा card भी उसी ढेर में बिना रुके ऊपर निकल जाता है 💨।
- **भाई-बहन वाला कार्ड:** एक बड़ी लाल "N" जैसी नहीं, बल्कि अपना बनाया हुआ TV icon 📺, उसके चारों तरफ़ छोटे-छोटे एक जैसे TV icons की भीड़, नीचे caption "GitHub पर family reunion 👨‍👩‍👧‍👦"। (कोई असली logo नहीं)
- **Psychology कार्ड (दो हिस्से):** ऊपर gold में `IKEA effect`, तीर, "खुद बनाया = ज़्यादा कीमती लगता है 🪑"; नीचे gold में `von Restorff effect`, तीर, "भीड़ में जो अलग, वही याद"; visual: 9 ग्रे डिब्बे और एक gold डिब्बा।
- **मोहल्ला test:** gold में `मोहल्ला test`, नीचे bubble "क्या कोई असली इंसान इसे कल से use करेगा?"; फिर before → after: `E-commerce clone` → 🏪 "Kirana order + stock alert", `Netflix clone` → 🎓 "Lecture library + progress bar"।
- **Proof कार्ड:** तीन checkbox टिक होते हैं: "✅ deploy (live link)", "✅ असली users", "✅ एक सच्चा number"; नीचे interview bubble "Features नहीं, कहानी 📖"।
- **CTA:** chat bubble "PIVOT" + follow button।

## 📄 Cheat sheet (comment → DM)
**नाम:** Clone → Customer Upgrade Sheet · **Keyword:** PIVOT
- **E-commerce clone → kirana दुकान app:** WhatsApp जैसा सीधा order form, stock घटते ही "low stock" alert, उधार (credit) का हिसाब। Metric: हफ्ते के orders, stock खत्म होने के मामले।
- **Netflix clone → college lecture library:** subject और unit के हिसाब से videos, हर student का progress bar, "जहाँ छोड़ा वहीं से" play, exam से पहले "बाकी lectures" list। Metric: कितने students रोज़ आते हैं, average completion।
- **Spotify clone → college club का podcast/audio notes app:** subject-wise playlists, episode पर listen count, slow internet के लिए छोटी audio files। Metric: weekly listeners।
- **Swiggy/Zomato clone → canteen pre-order:** class के बीच order, token number, "ready" होने पर notification, rush hour में queue कम। Metric: रोज़ के pre-orders।
- **Twitter/X clone → hostel complaint board:** complaint post, upvote, status (open → in progress → fixed), warden/admin dashboard। Metric: complaint fix होने का average time।
- **Uber/Ola clone → students का cab-sharing:** station या airport जाने वालों को same time पर match करना। Metric: कितनी rides share हुईं।
- **Instagram clone → college events + lost & found:** event photos, "खोया/मिला" posts, ID card मिला तो owner को notify। Metric: कितनी चीज़ें वापस मिलीं।
- **Deploy ज़रूरी:** free/सस्ते options (जैसे Vercel, Netlify, Render या Firebase; free plans और limits बदलते रहते हैं, sign up से पहले check करो)। Resume पर live link + GitHub दोनों।
- **README का format:** Problem (1 line) · किसके लिए (असली user) · Live link + 30 sec demo video · Tech stack · 1 सच्चा metric · आगे क्या बनाओगे।
- **Interview में कहानी ऐसे बोलो:** "Uncle को stock याद नहीं रहता था → मैंने ये बनाया → 3 हफ्ते चला → ये सीखा/ये बदला"। Number वही बोलो जो सच में measure किया।

## ✅ ध्यान रखो / सोर्स
- **"Clone बनाया तो resume dustbin में" जैसा absolute मत बोलो।** Clone सीखने के लिए बढ़िया है; बात बस इतनी है कि भीड़ में अलग दिखना मुश्किल होता है।
- "Recruiter X seconds में resume देखता है" जैसे stats नहीं डाले; VO में सिर्फ scene है।
- Metric कभी invent मत करो। VO में "एक सच्चा number" इसी वजह से है।
- असली दुकान/college का data use करो तो **permission लो**; customers के phone numbers या students का data public repo में नहीं; API keys/.env commit नहीं।
- App में Netflix/Spotify/Zomato के **logo, नाम या brand colors** मत use करो (trademark); project का नाम अपना रखो। स्क्रीन पर भी कोई असली logo नहीं।
- Rule का नाम अपना: **मोहल्ला test**। दूसरे creator का framework नाम या lines नहीं लीं।
- DM का वादा तभी जब Instagram comment-keyword automation (जैसे ManyChat) चालू हो, वरना manually भेजो।
- **सोर्स:**
  - IKEA effect: Norton, Mochon & Ariely (2012), "The IKEA effect: When labor leads to love", *Journal of Consumer Psychology* 22(3), 453–460. doi:10.1016/j.jcps.2011.08.002 (लोगों ने अपनी बनाई चीज़ों को experts की बनाई चीज़ों जितना कीमती आंका, और सोचा दूसरे भी ऐसा ही सोचेंगे।)
  - von Restorff (isolation) effect: Hedwig von Restorff (1933), "Über die Wirkung von Bereichsbildungen im Spurenfeld", *Psychologische Forschung* 18, 299–342. (एक जैसी चीज़ों की list में अलग दिखने वाली चीज़ ज़्यादा याद रहती है।)
