# P11 · Resume है या शादी का buffet?
**Series:** प्लेसमेंट का सच · **लंबाई:** करीब 74 सेकंड · **Keyword:** RESUME · **एक सीख:** कमज़ोर skills strong skills को भी हल्का कर देती हैं, इसलिए resume पर सिर्फ वो लिखो जिसे तुम interview में defend कर सको।

## 🎙️ वॉइसओवर
तुम्हारे resume पर बारह skills हैं और दोस्त के resume पर सिर्फ तीन, फिर भी shortlist उसी का हुआ। तुम्हारा resume शादी के buffet जैसा है, चालीस dishes हैं, पर याद एक भी नहीं रहती। इसके पीछे dilution effect है, यानी strong बातों के साथ कमज़ोर या बेकार बातें जुड़ जाएँ, तो पूरी impression कमज़ोर हो जाती है। मान लो, बस समझाने के लिए, Java, DSA और SQL में तुम दस में से आठ हो, तो तस्वीर strong है। अब उसमें सात ऐसे frameworks जोड़ दो जिनमें तुम दस में से तीन हो, तो average आठ से गिरकर साढ़े चार पर आ जाता है। दूसरी problem ये है कि resume की हर line पर सवाल आ सकता है, जैसे Docker लिखा है, तो image और container का फर्क भी पूछा जा सकता है। इसलिए हर skill पर पाँच मिनट test लगाओ। पहला, क्या तुम इस पर पाँच मिनट बिना अटके बोल सकते हो? दूसरा, क्या किसी project में इसका असली use दिखा सकते हो? अगर किसी एक का भी जवाब ना है, तो उसे हटाओ और पहले सीखो। कम skills पर पूरा भरोसा, यही strong resume है। Comment में RESUME लिखो, मैं तुम्हें role-wise skills और format वाली sheet DM कर दूँगा, और follow कर लो।

## 🎬 स्क्रीन + मीम
- **Hook (split screen):** बाएँ लंबा resume, skills की लंबी list नीचे तक लुढ़कती हुई; दाएँ छोटा resume, सिर्फ 3 skills, ऊपर हरा "Shortlisted ✅"। बीच में stick figure तुम 😳।
- **Buffet कार्ड:** stick figure प्लेट लेकर लंबी counter line के सामने, हर dish पर एक framework का नाम (React, Angular, Vue, Flutter, Django, Kotlin...), नीचे caption "40 dishes, याद एक भी नहीं 🍽️"।
- **Psychology कार्ड:** gold में `dilution effect`, तीर, नीचे: "strong + कमज़ोर बातें = पूरी impression कमज़ोर"।
- **"मान लो" graph:** ऊपर छोटा टैग "मान लो · सिर्फ समझाने के लिए"; 3 हरी bars (8, 8, 8) → average line 8; फिर 7 छोटी नारंगी bars (3) जुड़ती हैं → average line गिरकर 4.5 📉।
- **Interview bubble:** interviewer stick figure, bubble "Resume पर Docker लिखा है… image और container में फर्क?" तुम्हारे सिर पर पसीने की बूँद 💧।
- **5 मिनट test + CTA:** gold में `5 मिनट test`, दो checkbox: "5 मिनट बिना अटके बोल सकते हो?" · "project में असली use?" → एक भी ❌ तो skill पर लाल लकीर; फिर chat bubble "RESUME" + follow button।

## 📄 Cheat sheet (comment → DM)
**नाम:** Skill Section Kit (role-wise ज़रूरी skills + format) · **Keyword:** RESUME
- **Format (एक line, एक category):** `Languages: Java, Python` · `Frameworks: Spring Boot, React` · `Databases: MySQL` · `Tools: Git, Docker` · `Core: DSA, OOP, DBMS, OS, Computer Networks`। सबसे strong चीज़ हर line में पहले।
- **SDE / Backend:** एक language गहराई से (Java, C++ या Python), DSA, OOP, DBMS + SQL, OS और CN के basics, Git, एक backend framework (Spring Boot, Node.js + Express या Django), REST APIs।
- **Frontend:** HTML, CSS, JavaScript अच्छे से, फिर एक framework (React या Angular), TypeScript basics, API call करना, Git, browser DevTools।
- **Full stack:** Frontend + Backend वाली list में से एक-एक stack पूरा (जैसे React + Node/Express + MongoDB या SQL), और एक deployed project।
- **Data Analyst:** Excel/Google Sheets, SQL (joins, group by, window functions), Python (pandas), एक BI tool (Power BI या Tableau), statistics के basics।
- **ML / Data Science:** Python, NumPy, pandas, scikit-learn, probability और statistics, SQL, एक deep learning framework (PyTorch या TensorFlow), model evaluation (train/test split, overfitting)।
- **Android:** Kotlin, Android SDK / Jetpack Compose, API integration, Git, Play Store या APK वाला एक app।
- **5 मिनट test:** हर skill के लिए खुद से पूछो: (1) 5 मिनट बिना अटके बोल सकता हूँ? (2) किसी project/internship bullet में इसका असली use है? किसी एक का भी जवाब ना → हटाओ या पहले सीखो।
- **Proof rule:** skill section की हर skill कम से कम एक project या experience bullet में दिखनी चाहिए, जैसे "Spring Boot से REST API बनाई जो login और orders handle करती है"।
- **मत करो:** skill bars या "Java 80%" जैसे percentages (इनका कोई fixed मतलब नहीं होता), MS Word/Paint जैसे बहुत basic tools की लंबी list, या JD के वो keywords जो तुम्हें सच में नहीं आते।

## ✅ ध्यान रखो / सोर्स
- **"मान लो" वाला average सिर्फ समझाने के लिए है**, research के numbers नहीं। Dilution effect की असली research में judgments कम extreme हो गए थे; authors ने इसे representativeness heuristic से समझाया। VO में "मान लो, बस समझाने के लिए" साफ़ बोला गया है, उसे मत हटाना।
- "10 skills लिखीं तो reject" जैसा absolute दावा नहीं। Shortlist वाला hook एक scene है, rule नहीं।
- "Interviewer resume पर से **कुछ भी** पूछ **सकता** है" बोलो, "**हर** skill पर **ज़रूर** पूछेगा" नहीं।
- Docker fact सही है: **image** = read-only template, **container** = उस image का चलता हुआ instance।
- Skill bars/percentages वाली बात आम सलाह है, research नहीं; इसलिए cheat sheet में सिर्फ "fixed मतलब नहीं होता" लिखा है।
- Test का नाम अपना: **5 मिनट test**। दूसरे creator की lines या numbers नहीं लिए।
- DM का वादा तभी जब Instagram comment-keyword automation (जैसे ManyChat) चालू हो, वरना manually भेजो।
