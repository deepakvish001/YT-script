# P25 · Logic ready, उंगलियाँ slow
**Series:** प्लेसमेंट का सच · **लंबाई:** करीब 74 सेकंड · **Keyword:** TYPING · **एक सीख:** Code की speed सबसे पतले हिस्से से तय होती है, और typing वो हिस्सा है जिसे रोज़ 15 मिनट की practice से सीधे सुधारा जा सकता है।

## 🎙️ वॉइसओवर
Logic दोनों का ready था, पर दोस्त 20 मिनट में submit करके निकल गया, और तुम दो उंगलियों से ऐसे type कर रहे हो जैसे कबूतर दाना चुग रहा हो। Code लिखने के तीन हिस्से हैं, logic सोचना, उसे code में बदलना, और type करना। Speed सबसे पतला हिस्सा तय करता है, टंकी कितनी भी बड़ी हो, नल पतला है तो बाल्टी धीरे ही भरेगी। Slow typing सिर्फ़ time नहीं खाती, हर key ढूंढने में दिमाग keyboard में फँसता है और logic का धागा टूट जाता है। इसे cognitive load कहते हैं, यानी दिमाग पर एक साथ पड़ा बोझ। इसका इलाज है typing को autonomous stage तक ले जाना, यानी इतना automatic कि सोचना ना पड़े, जैसे cycle चलाना। और तीनों में typing सबसे सीधा fix है, इसी महीने से रोज़ 15 मिनट दो। पहले keybr या monkeytype पर touch typing सीखो, यानी keyboard देखे बिना type करना, accuracy पहले और speed बाद में। फिर brackets और semicolon की practice करो, क्योंकि code में symbols बहुत आते हैं। और VS Code shortcuts सीखो, जैसे Alt और arrow से line ऊपर नीचे होती है। Comment में TYPING लिखो, मैं तुम्हें 15 दिन का plan और shortcuts DM कर दूँगा, और ऐसे ही placement के सच के लिए follow कर लो।

## 📄 Cheat sheet (comment → DM)
**नाम:** 15-Day Typing Plan + Editor Shortcuts · **Keyword:** TYPING
- **Day 0 (बेस):** monkeytype पर 3 test दो (English, 30 sec), average WPM और accuracy लिख लो। Compare सिर्फ़ अपने से करना है, दोस्त से नहीं।
- **Day 1–5 · Touch typing:** keybr.com पर रोज़ 15 मिनट। उंगलियाँ home row पर (`ASDF` / `JKL;`), नज़र screen पर, keyboard पर नहीं। Speed गिरेगी, ये normal है; accuracy पहले।
- **Day 6–10 · Punctuation + numbers:** monkeytype में punctuation और numbers on करो। फिर language में `code_python`, `code_java` या `code_c++` चुनो (ये उस language के keywords/शब्दों की list देता है)।
- **Day 11–15 · असली code:** monkeytype के custom mode में अपना ही पुराना solution paste करके type करो; या खाली editor में 3 template बिना देखे लिखो (binary search, BFS, two pointers)।
- **रोज़ 2 मिनट symbol drill:** `() {} [] <> ; == != && || ++ -> ::` बिना नीचे देखे। Normal English typing practice में ये कम आते हैं, इसलिए इन्हें अलग से drill करो।
- **Day 15:** Day 0 वाला test दोबारा, फ़र्क लिखो। आगे हफ़्ते में 3 दिन 10 मिनट काफ़ी है।
- **VS Code shortcuts (Windows):** `Alt + ↑/↓` line ऊपर/नीचे खिसकाओ · `Shift + Alt + ↑/↓` line की copy · `Ctrl + D` same शब्द का अगला occurrence भी select (multi-cursor) · `Ctrl + /` comment/uncomment · `Ctrl + Shift + K` line delete · `Ctrl + Enter` cursor कहीं भी हो, नीचे नई line।
- **और shortcuts:** `Ctrl + Shift + \` matching bracket पर jump · `Ctrl + ←/→` एक-एक शब्द jump · `Ctrl + Backspace` पूरा शब्द delete · `Shift + Alt + F` code format · `Ctrl + Space` suggestions।
- **Mac/Linux:** कई keys अलग हैं (Mac पर ज़्यादातर `Ctrl` की जगह `Cmd` और `Alt` की जगह `Option`, पर शब्द-jump `Option + ←/→` और शब्द-delete `Option + Backspace` है; suggestions दोनों पर `Ctrl + Space`)। VS Code में `Ctrl + K` फिर `Ctrl + S` (Mac: `Cmd + K`, `Cmd + S`) दबाओ, अपनी machine की पूरी list वहीं है।
- **Test से पहले:** OA platform का editor अलग हो सकता है, इसलिए उसके sample/practice test में shortcuts एक बार try कर लो।

## ✅ ध्यान रखो / सोर्स
- कोई "average typing speed" या "TurboType data" वाला नंबर VO में नहीं। अगर कभी नंबर चाहिए तो सिर्फ़ ये: 2018 की एक बड़ी online study (करीब 1.68 लाख volunteers) में average करीब 52 WPM था, और ये self-selected लोग थे, यानी पूरी आबादी का average नहीं।
- "Typing fix कर लो तो selection पक्का" मत बोलो; typing तीन हिस्सों में से एक है। Logic कमज़ोर है तो पहले वो।
- "Typing इसी महीने में 2x हो जाएगी" जैसा वादा नहीं; VO में सिर्फ़ इतना कि ये सबसे सीधा fix है क्योंकि इसमें बस रोज़ की practice चाहिए।
- Cognitive load वाली line का मतलब: जो काम अभी automatic नहीं है, वो working memory का हिस्सा लेता है। "Typing से IQ घटता है" जैसा कुछ नहीं।
- Shortcuts Windows के हैं; VO में "Alt और arrow" बोला है, Mac पर वो `Option + ↑/↓` है।
- कबूतर वाला visual अपना stick-drawing हो, किसी meme template से नहीं।
- **टंकी-नल** और **तीन हिस्से** हमारे अपने नाम/उदाहरण हैं।
- DM का वादा तभी जब comment-keyword automation (जैसे ManyChat) चालू हो, वरना manually भेजो।
