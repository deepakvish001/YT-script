# P09 · हर हफ्ते नया framework, फिर भी interview में खाली?
**Series:** प्लेसमेंट का सच · **लंबाई:** करीब 73 सेकंड · **Keyword:** SKILLS · **एक सीख:** Framework पत्ते हैं जो हर season बदलते हैं; language और fundamentals जड़ हैं जो interview में काम आती है।

## 🎙️ वॉइसओवर
एक दोस्त हर Monday नया framework शुरू करता है और Sunday तक उसका Hello World बनता है, जबकि दूसरा छह महीने से एक language और fundamentals में घुसा है, तो बताओ interview में बोलने को किसके पास ज़्यादा होगा? पहले वाले को लोग shiny object syndrome बोलते हैं, यानी हर नई चमकती चीज़ ज़्यादा ज़रूरी लगती है, और यहीं से tutorial hell शुरू होता है, जहाँ video पर video चलता है पर कुछ बनता नहीं। Kardas और O'Brien की 2018 की research में भी दिखा कि किसी को बार बार कोई skill करते देखने से confidence तो बढ़ा, पर असली performance नहीं बढ़ी। Frameworks बदलते रहते हैं, fundamentals नहीं, और बड़ी companies कई tools खुद बनाती हैं, जैसे Google ने Go बनाई और Apple ने Swift, इसलिए interview में अक्सर core logic देखा जाता है। तो मेरा जड़ पहले rule अपनाओ, यानी पहले एक language, DSA basics, HTTP, database और Git की जड़ पक्की करो, फिर एक ही framework से एक पूरा project deploy तक ले जाओ। नया framework तभी सीखो जब पुराना project पूरा हो और job में उसकी सच में ज़रूरत दिखे। Comment में SKILLS लिखो, मैं तुम्हें frontend, backend और data का core skills roadmap DM कर दूँगा, और follow कर लो।

## 🎬 स्क्रीन + मीम
- **Hook (calendar split):** बाएँ चार हफ्तों का calendar, हर Monday "New framework 🤩", हर Sunday "Hello World ✅", और कुछ नहीं; दाएँ दूसरा stick figure, जिसके नीचे एक पौधे की जड़ें हर हफ्ते और गहरी होती जाती हैं 🌱।
- **Shiny object मीम:** stick figure हवा में तैरती चमकती चीज़ों (बिना logo, सिर्फ़ ✨ वाले generic boxes: "Framework X", "Framework Y 2.0") के पीछे भागता है, हाथ में आधे-अधूरे projects का थैला।
- **Tutorial hell:** conveyor belt पर videos एक के बाद एक आते हैं, stick figure popcorn 🍿 के साथ बैठा, ऊपर counter "Watched: 47 · Built: 0"।
- **Research कार्ड:** दो bars, बिना numbers: `Confidence ↑↑` vs `Performance →`; नीचे छोटा "Kardas & O'Brien, 2018 · बार-बार देखना ≠ कर पाना"।
- **जड़ पहले (पेड़):** पेड़ की जड़ों पर labels `Language` · `DSA` · `HTTP` · `Database` · `Git`; ऊपर पत्तों पर generic "framework" labels जो पतझड़ 🍂 में गिरते और नए उगते हैं; gold में `जड़ पहले`। साइड में छोटा tag: "Go → Google · Swift → Apple"।
- **CTA:** तीन cards `Frontend` · `Backend` · `Data`, फिर "Comment: SKILLS" bubble + follow button।

## 📄 Cheat sheet (comment → DM)
**नाम:** जड़ पहले: role-wise core skills roadmap · **Keyword:** SKILLS
- **सब roles की common जड़:** एक language गहराई से, DSA basics (arrays, hashing, sorting, trees, graphs), Git, Linux command line, HTTP का basic, SQL का basic, और official docs पढ़ने की आदत।
- **Frontend · जड़:** semantic HTML; CSS (box model, flexbox, grid, responsive); JavaScript core (closures, `this`, event loop, promises); DOM + events; browser basics (caching, CORS); accessibility की शुरुआत।
- **Frontend · पत्ते (बाद में):** एक framework (React, Angular या Vue में से **एक**), फिर TypeScript, testing, build tools।
- **Backend · जड़:** एक language (Java, Go, Python या Node.js); HTTP + REST API design; SQL (joins, indexing, transactions); authentication (session vs token); caching की basic समझ; OS / CN basics (threads, TCP)।
- **Backend · पत्ते (बाद में):** एक framework (Spring Boot, Express, Django या FastAPI में से **एक**), Docker, message queues, cloud की basics।
- **Data · जड़:** Python + NumPy / pandas; SQL; statistics और probability; data cleaning + visualization; linear algebra की intuition।
- **Data · पत्ते (बाद में):** scikit-learn, फिर PyTorch या TensorFlow, experiment tracking।
- **नया framework सीखने से पहले दो सवाल:** (1) पिछला project पूरा और deployed है? (2) जिन roles के लिए apply कर रहे हो, उनकी job descriptions में ये बार-बार दिख रहा है? दोनों का जवाब हाँ हो, तभी।
- **Tutorial hell से निकलने का तरीका:** एक section देखो, video बंद करो, वही feature बिना देखे खुद बनाओ; फिर एक feature ऐसा जोड़ो जो tutorial में था ही नहीं।

## ✅ ध्यान रखो / सोर्स
- **मत बोलो:** "HackerRank data साबित करता है…", "frameworks सिर्फ़ 3 साल जीते हैं", "framework सीखना बेकार है"। Framework ज़रूरी है, बस जड़ के बाद और एक बार में एक।
- "Shiny object syndrome" और "tutorial hell" आम बोलचाल के शब्द हैं, formal psychology terms नहीं; इसीलिए VO में "लोग बोलते हैं"। असली research वाली बात सिर्फ़ Kardas & O'Brien की है।
- Kardas & O'Brien ने darts, moonwalk और एक video game जैसी skills पर test किया था, coding पर नहीं; VO में "कोई skill" कहा है, "research ने coders पर साबित किया" मत बोलो।
- Go और Swift आज open source हैं और बाहर भी खूब use होते हैं; इन्हें "internal secret tools" मत बोलो। Point सिर्फ़ इतना है कि बड़ी companies ज़रूरत पड़ने पर अपने tools खुद बना लेती हैं।
- "Interview में अक्सर core logic देखा जाता है": "अक्सर" रखो, "हमेशा" नहीं; कई roles में framework-specific सवाल भी आते हैं।
- Framework का नाम अपना है: **जड़ पहले rule**।
